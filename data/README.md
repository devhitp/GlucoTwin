# Data Directory

This directory contains datasets used by GlucoTwin.

- `raw/`: Place the original OhioT1DM dataset files here. DO NOT modify them.
- `processed/`: Intermediate and processed files generated by GlucoTwin.

**Important:** The OhioT1DM dataset is sensitive research data. These directories are ignored by git to prevent accidental commits. DO NOT remove the gitignore protection.
